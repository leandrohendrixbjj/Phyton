1. CPython

  - Python é a linguagem; CPython é o programa que executa essa linguagem.
  - O interpretador principal do CPython é escrito principalmente em C.


2. Fluxo

  - Você escreve o código Python:

    ```python
    print("Hello, World!")
    ```

  1. Código-fonte (.py) $\rightarrow$ Bytecode (.pyc): Ocorre uma fase de compilação pura. O código legível por humanos é 
     transformado em instruções de baixo nível (bytecode) otimizadas para uma máquina virtual.

  2. Bytecode $\rightarrow$ Linguagem de Máquina: A PVM (Python Virtual Machine) lê esse bytecode e o executa instrução por 
     instrução, traduzindo-o para código de máquina em tempo de execução.   


3. Então Python é compilado ou interpretado?

  - Python, especificamente CPython, utiliza compilação + interpretação.
  - O código é compilado para bytecode e, no CPython, esse bytecode é executado pela Python Virtual Machine.

  - Linguagens 100% compiladas: o código-fonte é compilado antecipadamente, diretamente para código de máquina, que depois é 
    executado pela CPU.
