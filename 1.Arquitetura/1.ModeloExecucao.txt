1. CPython

  - Python é a linguagem; CPython é o programa que executa essa linguagem.
  - O interpretador principal do CPython é escrito principalmente em C.


2. Fluxo

  - Você escreve o código Python:

    ```python
    print("Hello, World!")
    ```

  - O CPython compila esse código para bytecode. (Etapa de compilação)
  - A Python VM do CPython executa esse bytecode. (Etapa de interpretação)
  - O CPython, que é um programa nativo, realiza as operações necessárias para que a CPU execute o trabalho.


3. Então Python é compilado ou interpretado?

  - Python, especificamente CPython, utiliza compilação + interpretação.
  - O código é compilado para bytecode e, no CPython, esse bytecode é executado pela Python Virtual Machine.

  - Linguagens 100% compiladas: o código-fonte é compilado antecipadamente, diretamente para código de máquina, que depois é executado pela CPU.
